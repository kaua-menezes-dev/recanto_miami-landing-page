# Testimonials — Editorial Couple Stories

**Status:** Editorial carousel direction chosen over dense card columns.

## Objective
Make testimonials feel personal and visually authentic while demonstrating the venue's reliability. This is not a generic SaaS-style reviews wall.

## Desired composition
- One real couple / event image shown prominently.
- One authentic review in a spacious, editorial text area.
- Customer name (only as authorized), optional wedding/event context and unobtrusive previous/next controls.
- Smooth image and text transition with calm pacing.
- Natural surfaces from Botanical Luxury; typography remains highly readable.

Reference for the direction: https://21st.dev/@ravikatiyar162/components/testimonial  
Earlier candidate (not selected as main structure): https://21st.dev/@avanishverma4/components/testimonial-v2

## Interaction rules
- Manual navigation must be apparent; if autoplay is proposed it requires explicit design review and must pause for interaction.
- Mobile swipe is allowed but visible controls remain important.
- Ensure text length is reasonable; do not cut testimonials in misleading ways.
- Reduced-motion variant should avoid theatrical movement.

## Source content
Audit testimonials from existing Recanto Miami sources; obtain approval for quotations, names and related photographs. Grupo Miami Eventos' public testimonials may contain stories from more than one venue: **verify venue attribution** before reusing any quote.

Potential audit sources (not content licenses):
- https://www.grupomiamieventos.com.br/depoimentos
- https://www.casamentos.com.br/chacara-casamento/chacara-recanto-miami-eventos--e149909/opinioes

## Never do
- Fabricate customer names or reviews.
- Pair a random wedding photo with an unrelated review.
- Rewrite a quotation in a way that changes its meaning.
- Claim ratings or award counts without a verified, date-appropriate source and approval.
