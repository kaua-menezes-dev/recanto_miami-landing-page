# Reference Library — Roles, Not Copies

**Status:** User-selected sources, confirmed direction. Use these references for intended *behavior and principles*, never clone an entire brand or copy unlicensed imagery/text.

## Main visual / motion inspiration

https://healingminds.pl/

**Study:** fluid page rhythm; elegant transitions between content sections; deliberate pacing; spacious composition; emotional storytelling; subtle image scale changes. **Adapt** the tranquil sensibility to Botanical Luxury. **Do not import** psychotherapy-related imagery, Polish copy or brand-specific colors.

### Midu Studio — SECONDARY
https://midu.design/

**Study:** editorial typography, high-contrast hierarchy, spatial composition, scale-based reveal transitions, creative project presentation. **Do not import** the agency's exact branding, copy, dramatic unrelated color identity or overly technical feeling.

### Infinite Scroll Gallery with Page Transitions using GSAP — Codrops

### Perspective Tunnel Hero — 21st.dev, Daiwiik Harihar

## Design-review protocol
For each proposed section, show which *specific aspect* comes from which reference. Label as: **faithful interaction**, **adapted interaction**, or **mood-only**. Do not present a link as proof of implementation feasibility. Validate mobile and reduced-motion variants separately.

## Source and licensing constraints
Publicly visible websites are inspiration, not a permission grant. Verify license terms of any copied component or demo before use; retain attribution where required. Real wedding photography/video needs confirmation from the venue and relevant rights holders. Nothing in these links authorizes scraping and republishing media.
